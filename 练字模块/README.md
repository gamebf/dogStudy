# 练字模块（三年级上册 · 语数英书写练习）

帮助三年级孩子练习书写的可打印字帖，内容结合上海教材。**每日 1 页（语/数/英各 1 页），每天少量，60 天练完。**

## 文件说明

| 文件 | 对应教材 | 内容 |
|---|---|---|
| `index.html` | — | 练字模块入口，点选科目 |
| `语文-字帖.html` | 统编版（部编版）语文 三上 | 生字（田字格 + 拼音 + 笔顺动画）、词语、句子 |
| `数学-字帖.html` | 沪教版数学 三上 | 数字、算式对位、数学用语（方格） |
| `英语-字帖.html` | 牛津上海版英语 3A | 26 字母、核心单词、核心句型（四线三格） |

## 核心特性

- **按 60 天拆分**：每科每天 1 页，页内只有当天内容，打印即当天一页。
- **A4 纸张**：已内置 `@page { size: A4 }`，格子大小按一页的量适配。
- **语文带拼音**：每个生字田字格上方有拼音格（范字拼音红 + 描红浅色 + 空拼音格临写），多音字按课文读音标注。
- **笔顺动画**：语文生字点击红色范字，笔画会「一笔一笔」出现（离线可用，已打包 hanzi-writer 及笔画数据）；纸上另标「笔顺：横、竖、撇…」供照写。

## 使用方法

1. 浏览器打开 `index.html`，点选科目。
2. 用「上一天 / 下一天」或输入天数切换到当天。
3. 点「打印本页」或按 `Ctrl + P` 打印。

打印设置建议：
- 纸张：**A4，纵向**
- 边距：默认或「窄」
- **勾选「背景图形」**（重要，否则田字格/四线三格/拼音线可能不显示）
- 比例：100%

## 内容量说明（60 天）

- **语文**：251 个生字 / 21 课 → 每天约 5 字，前 51 天学新字、后 9 天复习易错/多音字；每天另配 2 个词语，每 3 天 1 句。
- **数学**：数字 0~9、10~20、整十整百、6 道算式、13 组用语，25 天一轮 + 复习循环，共 60 天。
- **英语**：26 字母（1~13 天）→ 77 个核心单词（14~39 天）→ 17 个句型（40~56 天）→ 复习（57~60 天）。

## 使用建议

- **不追求量**：每天语、数、英各练 5~10 分钟，重点在「慢、准、好」。
- **先看动画、再描红、最后临写**：语文生字先点击范字看笔顺，再描红 1~2 遍，最后在空格独立写。
- **作业与练字分开**：不纠结工整，避免「赶作业」把字写坏。
- **重点攻易错**：不必每天练全部，挑孩子写得最差的集中练习。

## 修改内容

- 三科文件底部各有一段数据数组（`DAYS`），格式清晰，改字即可（例如生字、拼音、词语、句子）。
- 语文笔顺/笔画动画数据由构建脚本自动生成（见 `../tools/build.js`）。若**增删生字**，需要重跑构建脚本以更新笔画数据：

  ```bash
  node tools/build.js
  ```

  （脚本会联网抓取 hanzi-writer 笔画数据并缓存到 `tools/hanzi-cache.json`。）

## 重要提示（请务必核对）

教材内容按标准版本编写，可能存在差异：

- **语文**：生字表、词语、拼音（多音字）请对照孩子课本「写字表」核对。
- **数学**：沪教版三上单元顺序、概念词请对照课本目录核对。
- **英语**：牛津上海版 3A 各单元单词请对照课本 Word list 核对。

如发现差异，按上面「修改内容」方式调整即可。
